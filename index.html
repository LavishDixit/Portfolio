JanSahayak: AI Government Document Assistantv1 complete, upgrading

Sep 2026 – Present · Solo project

Scheme details are buried in long, scanned PDFs, often in Hindi. I wanted answers that show exactly which document they came from.

  • Independently developed a bilingual (English/Hindi) RAG assistant that answers scheme questions from 63 government documents (Central, Madhya Pradesh, Rajasthan) with source citations, served via FastAPI.
  • Implemented hybrid retrieval pairing multilingual ChromaDB embeddings with BM25 over 2,128 chunks, moving the correct document from rank 8 to rank 1 on a benchmark query versus semantic-only search.
  • Created a bilingual Tesseract OCR pipeline for scanned circulars (21 of the first 44 documents) after fixing unreadable Hindi output.
  • Trained a TF-IDF + Logistic Regression classifier (85% accuracy, macro F1 0.84); added spaCy entity extraction and LLM summaries.
  • Now reworking the backend into a lightweight, deployable version. These figures are from v1 and will be updated.

SummarAIze: AI Webpage Summarizer

May 2026 – Jun 2026 · Chrome extension

Long articles waste time. I wanted a summary in my own language, one click away.

Semantic Search System with Semantic Cache
